# AdvancedTween Editor

Static AdvancedTween editor bundle mirrored from:

https://html-classic.itch.zone/html/16843642/advancedtween-editor1.2.0/index.html?v=1782685120

The app is plain HTML/CSS/JavaScript. The itch helper script is vendored in
`vendor/htmlgame.js` so the bundle can run without depending on
`https://static.itch.io/htmlgame.js` at runtime.
